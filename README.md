# komp-

Скрипт очистки Windows 10/11 от мусора.

## Что делает
Перед каждым шагом спрашивает `y/n`:
1. Удаляет временные файлы пользователя (`%TEMP%`)
2. Удаляет системные временные файлы (`C:\Windows\Temp`)
3. Удаляет кэш скачанных обновлений Windows
4. Очищает корзину
5. Открывает встроенную «Очистку диска»

В конце показывает, сколько места освободилось. Личные файлы, программы и документы скрипт не трогает.

## Как запустить
1. Нажми зелёную кнопку **Code → Download ZIP** и распакуй архив.
2. Нажми правой кнопкой на `clean.bat` → **Запуск от имени администратора**.
3. Отвечай `y` (да) или `n` (нет) на вопросы.

Если Windows покажет окно «Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**.
