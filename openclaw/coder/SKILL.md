# Задачи по коду

Код ты не пишешь сам в чате. Ты ставишь задачу в очередь, её делает Claude Code на сервере
в отдельной ветке, а отчёт сам приходит владельцу в Telegram. Очередь работает круглые сутки:
задача, данная днём, начинается сразу; данная перед сном, будет готова к утру.

Все команды: `python3 __CODER__ <команда>`. Отвечай владельцу тем, что напечатала команда.

## Новая задача

`python3 __CODER__ add --repo komp- "<задача>"`

- Перепиши просьбу владельца в полную задачу: что именно поменять, где (страница, раздел,
  файл, если он назвал), как должно стать в итоге. Сохрани все детали, которые он дал,
  ничего не выдумывай. Голосовое сначала расшифруй.
- Если из сообщения неясно даже, о каком проекте или экране речь, спроси владельца до
  постановки. Мелкие неясности не спрашивай: исполнитель сам задаст вопрос, если упрётся.
- Сейчас доступен только репозиторий `komp-` (в нём и «Сводка»: `openclaw/dashboard`).
  Если просят про другой проект, скажи, что его ещё не подключили к очереди.
- Несколько независимых правок в одном сообщении ставь отдельными задачами.

## Ответы владельца

| Владелец пишет | Команда |
|---|---|
| что с задачами / что в очереди | `list` (все: `list --all`) |
| подробнее про N | `show N` |
| ответ N: … (на вопрос исполнителя) | `answer N "<ответ>"` |
| переделать N: … | `redo N "<что не так и как надо>"` |
| принять N / да, сливай N | `merge N` |
| отменить N / стоп N | `cancel N` |

Если владелец отвечает на отчёт без номера, а активная задача одна, бери её номер.
Если задач несколько, уточни номер.

## Что нельзя

- `merge` только по прямому «принять» или «да» владельца на конкретную задачу.
- Не выкладывай изменения на сервер и не перезапускай службы после слияния без отдельного
  «да» владельца.
- Не пересказывай и не показывай токены и файлы из `~/.config/jarvis`.
