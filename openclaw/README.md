# Джарвис и «Сводка» на своём сервере

Пишешь или говоришь боту в Telegram: «потратил 500 на такси», «надо купить подарок маме до четверга», «план: накопить на отпуск к маю», «по работе: ответить на отзыв в 2ГИС», «запомни: у Димы день рождения 12 марта». Бот записывает трату, дело, план или заметку. Все записи сразу видны на дашборде «Сводка»: на первой странице личное (траты, дела, планы, заметки), на второй работа (рабочие дела, заметки и быстрые ссылки на сайт, CRM, 2ГИС). Он открывается по ссылке с паролем с телефона, компа или планшета. На дашборде их тоже можно добавлять, отмечать и удалять, и Джарвис увидит изменения.

Как это устроено:

```
Telegram ──► OpenClaw (Джарвис) ──┐
                                  ├──► файлы на сервере: траты, дела, заметки
браузер ──► Caddy (HTTPS, пароль) ──► дашборд ──┘
```

- **Сервер (VPS):** на нём круглосуточно работают Джарвис и дашборд.
- **OpenClaw + Claude Code:** сам Джарвис. Думает Claude через Claude Code, который стоит на этом же сервере и вошёл в твой аккаунт, поэтому расход идёт из лимитов твоей подписки, а не по отдельному счёту. Скил `life-ledger` из этой папки учит его вести учёт.
- **Groq:** расшифровывает голосовые. У него есть бесплатный тариф.
- **Дашборд** (`dashboard/`): маленький сайт на Python. Он показывает те же файлы, которые ведёт Джарвис.
- **Caddy:** даёт дашборду адрес с HTTPS (вида `https://1-2-3-4.sslip.io`, свой домен покупать не нужно) и закрывает его паролем.

Данные лежат обычными файлами в `~/.openclaw/workspace/life/`: `expenses.csv` (траты), `food.csv` (еда и калории), `settings.json` (норма калорий), `receipts/` (разобранные чеки), `memory/` (общая память: страница на каждого человека, место, проект и тему, связанные через `[[ссылки]]`, как в Obsidian), `tasks.md` (дела), `plans.md` (планы), `notes.md` (заметки), `work-tasks.md` и `work-notes.md` (работа). Заметки и дела — обычный Markdown со ссылками `[[…]]` и `#тегами`, как в Obsidian. Их легко скачать, перенести или открыть в Excel.

Команды OpenClaw взяты из его официальной документации (github.com/openclaw/openclaw, октябрь 2026).

## Что понадобится

| Что | Где взять | Сколько стоит |
|---|---|---|
| VPS на Ubuntu 24.04, от 2 ГБ памяти | Hetzner, DigitalOcean, Timeweb и т.п. | ~$5–10 в месяц |
| Подписка Claude (Pro или Max) | у тебя уже есть | Джарвис тратит её лимиты, те же, что и твои чаты с Claude |
| Ключ Groq для голосовых | console.groq.com → API Keys | есть бесплатный тариф |
| Telegram-бот | @BotFather в Telegram | бесплатно |

Ключи и пароли никому не показывай и не присылай в чат, даже мне. Вставляй их только на сервере.

## Шаг 1. Зайди на сервер и создай пользователя

После покупки VPS тебе дадут IP-адрес и пароль от `root`. На Windows открой PowerShell и введи:

```bash
ssh root@ТВОЙ_IP
```

Создай отдельного пользователя. OpenClaw выполняет команды на сервере, и от имени `root` запускать его опасно:

```bash
adduser jarvis
usermod -aG sudo jarvis
```

## Шаг 2. Перекинь эту папку на сервер

1. На компьютере открой репозиторий на GitHub, ветку `claude/eager-mendel-oncysb`, нажми **Code → Download ZIP** и распакуй архив.
2. В **новом** окне PowerShell на компьютере (не на сервере) выполни, подставив свой путь к распакованной папке:

   ```powershell
   scp -r "$HOME\Downloads\komp--claude-eager-mendel-oncysb\openclaw" root@ТВОЙ_IP:/home/jarvis/
   ```

3. В окне, где ты зашёл на сервер, отдай папку пользователю `jarvis` и переключись на него:

   ```bash
   chown -R jarvis:jarvis /home/jarvis/openclaw
   su - jarvis
   ```

Все следующие команды выполняй под пользователем `jarvis`.

## Шаг 3. Поставь Claude Code и войди в аккаунт

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Если после установки команда `claude` не находится, закрой сессию (`exit`), снова выполни `su - jarvis` и повтори.

Войди в свой аккаунт Claude:

```bash
claude auth login
```

На сервере нет браузера, поэтому команда покажет ссылку. Открой её на телефоне или компьютере, войди в аккаунт, скопируй код, который покажет сайт, и вставь его обратно в окно сервера.

Проверь, что вход прошёл:

```bash
claude --version
claude auth status --text
```

## Шаг 4. Установи OpenClaw

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Установщик сам поставит нужную версию Node.js и запустит мастер настройки. В мастере:
- **модель (provider):** выбери **Claude CLI**. Тогда OpenClaw будет работать через Claude Code, в который ты вошёл на шаге 3. Ключ API не нужен;
- **запуск в фоне (daemon):** соглашайся, тогда ассистент будет работать постоянно.

Если мастер не запустился сам:

```bash
openclaw onboard --install-daemon
```

Проверь, что всё работает и Claude виден:

```bash
openclaw gateway status
openclaw models list --provider anthropic
```

**Важно про лимиты.** Джарвис расходует лимиты твоей подписки, те же самые, что и твои чаты с Claude. Если ты упрёшься в лимит в чатах, Джарвис тоже будет ждать до сброса, и наоборот. Для трат, дел и заметок он тратит мало. Если когда-нибудь дашь ему много работы, его можно перевести на отдельный ключ API, чтобы он не съедал твои лимиты.

Если Claude Code обновился и OpenClaw перестал отвечать, обнови его и перезапусти Джарвиса:

```bash
claude update
openclaw gateway restart
```

## Шаг 5. Подключи Telegram

1. В Telegram открой **@BotFather** (проверь, что ник именно такой), отправь `/newbot`, придумай имя и сохрани **токен**, который он выдаст.
2. На сервере выполни:

   ```bash
   openclaw channels add --channel telegram --token ТОКЕН_ОТ_BOTFATHER
   openclaw channels status --probe
   ```

3. Напиши своему боту в Telegram любое сообщение. Потом на сервере:

   ```bash
   openclaw pairing list telegram
   openclaw pairing approve telegram КОД_ИЗ_СПИСКА
   ```

   Код действует 1 час. После подтверждения бот отвечает только тебе, а чужие сообщения ждут твоего подтверждения.

## Шаг 6. Включи голосовые

Открой файл настроек:

```bash
nano ~/.openclaw/openclaw.json
```

Добавь внутрь главных фигурных скобок блок с ключом Groq (если блок `env` уже есть, допиши `GROQ_API_KEY` в него):

```json5
env: { vars: { GROQ_API_KEY: "gsk_ТВОЙ_КЛЮЧ" } },
```

Сохрани файл (Ctrl+O, Enter, Ctrl+X) и перезапусти ассистента:

```bash
openclaw gateway restart
```

Если бот не понимает голосовые, проверь, видит ли он Groq:

```bash
openclaw capability audio providers
```

## Шаг 7. Научи Джарвиса тратам, делам и заметкам

```bash
mkdir -p ~/.openclaw/workspace/skills
cp -r ~/openclaw/skills/life-ledger ~/.openclaw/workspace/skills/
```

Если в шаге 4 мастер выбрал другую рабочую папку (workspace), положи скил в `<твоя рабочая папка>/skills/`. Посмотреть её можно в `~/.openclaw/openclaw.json`.

## Шаг 8. Поставь дашборд «Сводка»

```bash
bash ~/openclaw/dashboard/install.sh
```

Скрипт спросит логин, пароль для дашборда и часовой пояс. Потом он сам поставит Caddy, запустит дашборд как службу и в конце покажет адрес вида `https://1-2-3-4.sslip.io`. Открой его на телефоне и добавь на главный экран («Поделиться → На экран „Домой“»), тогда дашборд будет открываться как приложение. Страница «Работа» открывается вкладкой сверху или сразу по адресу с `#work` на конце.

Быстрые ссылки на странице «Работа» (сайт Monotonica, CRM, 2ГИС, Harbin, Instafit) задаются списком `LINKS` в начале скрипта в `~/life-dashboard/index.html`.

Если рабочая папка OpenClaw не `~/.openclaw/workspace`, укажи папку с данными явно:

```bash
LIFE_DIR=<твоя рабочая папка>/life bash ~/openclaw/dashboard/install.sh
```

### Вкладка «ИИ»: чат с Claude, ChatGPT и бесплатными моделями

Вкладка устроена как приложение Claude. Слева панель: «Новый чат», поиск по названиям чатов, «Проекты» и «Недавние» (чаты без проекта). На телефоне и iPad в портретной ориентации панель выезжает по кнопке меню в шапке чата. У проекта есть название, описание (можно не заполнять) и общие инструкции: они добавляются в начало каждого чата этого проекта. Чат можно переименовать, перенести в проект или удалить через меню «...» у его строки. Если удалить проект, его чаты не пропадают, а переезжают в «Недавние».

Ответ приходит по частям, пока модель пишет. Кнопка «Стоп» останавливает ответ, уже написанная часть сохраняется. Ответы показываются с абзацами, списками и блоками кода, у блока кода есть кнопка «Копировать». Под каждым ответом подписано, какая модель отвечала.

Модель выбирается кнопкой рядом с полем ввода:
- **Авто:** отвечает Claude; когда лимит подписки Claude (5 часов или неделя) кончился, ChatGPT; если и он недоступен, бесплатная модель через шлюз. Если модель сменилась на ходу, чат пишет об этом;
- **Claude:** только Claude по подписке Claude Code, ключ ему не нужен;
- **ChatGPT:** подписка ChatGPT через Codex CLI, который уже установлен и залогинен на сервере (`codex login`). Вызывается как `codex exec` в песочнице только для чтения. Если Codex не найден или упёрся в лимит, пункт серый с причиной;
- **Бесплатная (авто):** шлюз сам выбирает бесплатную модель. Ниже в том же списке конкретные модели шлюза, сгруппированные по провайдерам (Groq, OpenRouter и т.д.), с поиском. Если шлюз недоступен, этого списка нет.

Данные о лимитах Claude пишет служба `jarvis-limits` в `~/.openclaw/workspace/coder/usage.json`, поэтому она должна работать. Чаты лежат в `life/ai/<id>.json`, проекты в `life/ai/projects.json`. Старые диалоги открываются как есть и попадают в «Недавние».

Бесплатные модели идут через локальный шлюз freellmapi, который должен работать на этом же сервере по адресу `http://127.0.0.1:3187`. Формат запросов как у OpenAI, модель `auto`: шлюз сам выбирает бесплатную модель (список его моделей: `http://127.0.0.1:3187/v1/models`). Отдельные ключи Gemini, Groq и OpenRouter для чата больше не нужны.

У шлюза один ключ. Он лежит только в файле `~/.config/jarvis/freellm-unified-key` и больше нигде, в репозиторий его не клади. Как положить ключ (вместо `КЛЮЧ` вставь свой):

```bash
mkdir -p ~/.config/jarvis && chmod 700 ~/.config/jarvis
printf '%s' 'КЛЮЧ' > ~/.config/jarvis/freellm-unified-key && chmod 600 ~/.config/jarvis/freellm-unified-key
```

Перезапускать ничего не надо. Если ключа нет или шлюз не отвечает, пункт «Бесплатная (авто)» виден серым с причиной, а при отправке чат пишет понятную ошибку, например «Бесплатный шлюз freellmapi недоступен (127.0.0.1:3187). Проверь, что он запущен.»

## Шаг 9. Проверь

Напиши боту или скажи голосом:
- «потратил 450 на продукты»
- «надо оплатить интернет до пятницы»
- «план: накопить 100 тысяч на отпуск к маю»
- «по работе: заказать плёнку до среды»
- «запомни: у Димы день рождения 12 марта»
- «сколько я потратил за октябрь?»
- «что по делам?»

Через 10 секунд всё это появится на дашборде: личное на первой странице, рабочее на вкладке «Работа». Добавь что-нибудь на дашборде и спроси Джарвиса: он это тоже увидит.

## Шаг 10. Задачи по коду

Джарвис принимает задачи по коду в любое время и отдаёт их Claude Code на сервере. Каждая задача делается в своей ветке `jarvis/task-N`, отчёт приходит в Telegram, в основную ветку попадает только после «принять N».

1. Создай на GitHub fine-grained токен только на нужные репозитории с правами Contents и Pull requests: Read and write.
2. Под jarvis положи его в файл (символы не видны):
   ```bash
   mkdir -p ~/.config/jarvis && chmod 700 ~/.config/jarvis
   read -rsp "GitHub token: " T; echo; printf '%s' "$T" > ~/.config/jarvis/github-token; chmod 600 ~/.config/jarvis/github-token; unset T
   ```
3. Поставь очередь и перезапусти Джарвиса:
   ```bash
   bash ~/komp/openclaw/coder/install.sh
   openclaw gateway restart
   ```

Что писать боту: «в komp- сделай …», «что с задачами?», «ответ 3: …», «переделать 3: …», «принять 3», «отменить 3». Журнал службы: `journalctl --user -u jarvis-coder -f`.

## Обновление

Когда в репозитории появилась новая версия, на сервере под пользователем `jarvis`:

```bash
cd ~/komp && git pull && cp -r ~/komp/openclaw/. ~/openclaw/ && cd ~
cp -r ~/openclaw/skills/life-ledger ~/.openclaw/workspace/skills/
cp ~/openclaw/dashboard/server.py ~/openclaw/dashboard/index.html ~/life-dashboard/
sudo systemctl restart life-dashboard
```

## Если что-то не работает

- Бот молчит: `openclaw channels status --probe` и `openclaw logs --follow`.
- Ошибка «unauthorized token»: токен скопирован не полностью. Возьми новый у @BotFather (`/token`).
- Дашборд не открывается: `sudo systemctl status life-dashboard caddy` и `sudo journalctl -u caddy -n 50`.
- Джарвис отвечает ошибкой про вход или модель: `claude auth status --text`. Если вход слетел, снова `claude auth login`.
- Общая диагностика OpenClaw: `openclaw doctor`.

## Безопасность

- Дашборд закрыт паролем и работает только по HTTPS. Пароль бери длинный и нигде больше не используй.
- Не открывай веб-панель OpenClaw (Control UI) в интернет. Смотри её через `openclaw dashboard` на сервере или по SSH-туннелю.
- Не подтверждай в `pairing` чужие коды.
- Обновляйся время от времени: `openclaw update` и `sudo apt upgrade`.
