# Джарвис и «Пульт жизни» на своём сервере

Пишешь или говоришь боту в Telegram: «потратил 500 на такси», «надо купить подарок маме до четверга», «запомни: у Димы день рождения 12 марта». Бот записывает трату, дело или заметку. Все записи сразу видны на дашборде, который открывается по ссылке с паролем с телефона, компа или планшета. На дашборде их тоже можно добавлять, отмечать и удалять, и Джарвис увидит изменения.

Как это устроено:

```
Telegram ──► OpenClaw (Джарвис) ──┐
                                  ├──► файлы на сервере: траты, дела, заметки
браузер ──► Caddy (HTTPS, пароль) ──► дашборд ──┘
```

- **Сервер (VPS):** на нём круглосуточно работают Джарвис и дашборд.
- **OpenClaw + Claude:** сам Джарвис. Скил `life-ledger` из этой папки учит его вести учёт.
- **Groq:** расшифровывает голосовые. У него есть бесплатный тариф.
- **Дашборд** (`dashboard/`): маленький сайт на Python. Он показывает те же файлы, которые ведёт Джарвис.
- **Caddy:** даёт дашборду адрес с HTTPS (вида `https://1-2-3-4.sslip.io`, свой домен покупать не нужно) и закрывает его паролем.

Данные лежат обычными файлами в `~/.openclaw/workspace/life/`: `expenses.csv` (траты), `tasks.md` (дела), `notes.md` (заметки). Их легко скачать, перенести или открыть в Excel.

Команды OpenClaw взяты из его официальной документации (github.com/openclaw/openclaw, октябрь 2026).

---

## Что понадобится

| Что | Где взять | Сколько стоит |
|---|---|---|
| VPS на Ubuntu 24.04, от 2 ГБ памяти | Hetzner, DigitalOcean, Timeweb и т.п. | ~$5–10 в месяц |
| Ключ Claude API | console.anthropic.com → API Keys | оплата по факту, для личного учёта это немного |
| Ключ Groq для голосовых | console.groq.com → API Keys | есть бесплатный тариф |
| Telegram-бот | @BotFather в Telegram | бесплатно |

Ключи и пароли никому не показывай и не присылай в чат, даже мне. Вставляй их только на сервере.

## Шаг 1. Зайди на сервер и создай пользователя

После покупки VPS тебе дадут IP-адрес и пароль от `root`. На Windows открой PowerShell и введи:

```bash
ssh root@ТВОЙ_IP
```

Создай отдельного пользователя. OpenClaw выполняет команды на сервере, и от имени `root` запускать его опасно:

```bash
adduser jarvis
usermod -aG sudo jarvis
```

## Шаг 2. Перекинь эту папку на сервер

1. На компьютере открой репозиторий на GitHub, ветку `claude/eager-mendel-oncysb`, нажми **Code → Download ZIP** и распакуй архив.
2. В **новом** окне PowerShell на компьютере (не на сервере) выполни, подставив свой путь к распакованной папке:

   ```powershell
   scp -r "$HOME\Downloads\komp--claude-eager-mendel-oncysb\openclaw" root@ТВОЙ_IP:/home/jarvis/
   ```

3. В окне, где ты зашёл на сервер, отдай папку пользователю `jarvis` и переключись на него:

   ```bash
   chown -R jarvis:jarvis /home/jarvis/openclaw
   su - jarvis
   ```

Все следующие команды выполняй под пользователем `jarvis`.

## Шаг 3. Установи OpenClaw

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Установщик сам поставит нужную версию Node.js и запустит мастер настройки. В мастере:
- **модель (provider):** выбери **Anthropic API key** и вставь ключ Claude;
- **запуск в фоне (daemon):** соглашайся, тогда ассистент будет работать постоянно.

Если мастер не запустился сам:

```bash
openclaw onboard --install-daemon
```

Проверь, что всё работает:

```bash
openclaw gateway status
```

## Шаг 4. Подключи Telegram

1. В Telegram открой **@BotFather** (проверь, что ник именно такой), отправь `/newbot`, придумай имя и сохрани **токен**, который он выдаст.
2. На сервере выполни:

   ```bash
   openclaw channels add --channel telegram --token ТОКЕН_ОТ_BOTFATHER
   openclaw channels status --probe
   ```

3. Напиши своему боту в Telegram любое сообщение. Потом на сервере:

   ```bash
   openclaw pairing list telegram
   openclaw pairing approve telegram КОД_ИЗ_СПИСКА
   ```

   Код действует 1 час. После подтверждения бот отвечает только тебе, а чужие сообщения ждут твоего подтверждения.

## Шаг 5. Включи голосовые

Открой файл настроек:

```bash
nano ~/.openclaw/openclaw.json
```

Добавь внутрь главных фигурных скобок блок с ключом Groq (если блок `env` уже есть, допиши `GROQ_API_KEY` в него):

```json5
env: { vars: { GROQ_API_KEY: "gsk_ТВОЙ_КЛЮЧ" } },
```

Сохрани файл (Ctrl+O, Enter, Ctrl+X) и перезапусти ассистента:

```bash
openclaw gateway restart
```

Если бот не понимает голосовые, проверь, видит ли он Groq:

```bash
openclaw capability audio providers
```

## Шаг 6. Научи Джарвиса тратам, делам и заметкам

```bash
mkdir -p ~/.openclaw/workspace/skills
cp -r ~/openclaw/skills/life-ledger ~/.openclaw/workspace/skills/
```

Если в шаге 3 мастер выбрал другую рабочую папку (workspace), положи скил в `<твоя рабочая папка>/skills/`. Посмотреть её можно в `~/.openclaw/openclaw.json`.

## Шаг 7. Поставь дашборд

```bash
bash ~/openclaw/dashboard/install.sh
```

Скрипт спросит логин, пароль для дашборда и часовой пояс. Потом он сам поставит Caddy, запустит дашборд как службу и в конце покажет адрес вида `https://1-2-3-4.sslip.io`. Открой его на телефоне и добавь на главный экран («Поделиться → На экран „Домой“»), тогда дашборд будет открываться как приложение.

Если рабочая папка OpenClaw не `~/.openclaw/workspace`, укажи папку с данными явно:

```bash
LIFE_DIR=<твоя рабочая папка>/life bash ~/openclaw/dashboard/install.sh
```

## Шаг 8. Проверь

Напиши боту или скажи голосом:
- «потратил 450 на продукты»
- «надо оплатить интернет до пятницы»
- «запомни: у Димы день рождения 12 марта»
- «сколько я потратил за октябрь?»
- «что по делам?»

Через 10 секунд всё это появится на дашборде. Добавь что-нибудь на дашборде и спроси Джарвиса: он это тоже увидит.

## Если что-то не работает

- Бот молчит: `openclaw channels status --probe` и `openclaw logs --follow`.
- Ошибка «unauthorized token»: токен скопирован не полностью. Возьми новый у @BotFather (`/token`).
- Дашборд не открывается: `sudo systemctl status life-dashboard caddy` и `sudo journalctl -u caddy -n 50`.
- Общая диагностика OpenClaw: `openclaw doctor`.

## Безопасность

- Дашборд закрыт паролем и работает только по HTTPS. Пароль бери длинный и нигде больше не используй.
- Не открывай веб-панель OpenClaw (Control UI) в интернет. Смотри её через `openclaw dashboard` на сервере или по SSH-туннелю.
- Не подтверждай в `pairing` чужие коды.
- Обновляйся время от времени: `openclaw update` и `sudo apt upgrade`.
